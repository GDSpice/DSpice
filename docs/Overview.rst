Overview
========

DSpice *(Designing Circuits and Simulation by SPICE)* is a comprehensive, open-source electronic design automation (EDA) tool that bridges the gap between complex circuit simulation and user-friendly design workflows. Built on top of the industry-standard **ngspice** simulation engine, DSpice provides an integrated environment for modeling, designing, simulating, and analyzing analog electronic circuits.

Core Capabilities
~~~~~~~~~~~~~~~~~~

**Model & Symbol Creation**  
Develop custom SPICE models for analog components and create corresponding schematic symbols with an intuitive library management system.

**Schematic Capture**  
Design circuits using a CAD-based schematic editor that simplifies the process of connecting components and defining circuit topologies.

**Circuit Simulation**  
Leverage the full power of ngspice to perform various analyses including:
- Operating Point (OP) Analysis
- DC Sweep Analysis  
- Transient (Time-Domain) Analysis
- AC/Frequency-Domain Analysis 

**Waveform Visualization**  
View and analyze simulation results through a dedicated waveform viewer that displays voltage, current, and power characteristics 
across different operating points.

Why DSpice?
~~~~~~~~~~

Unlike traditional SPICE tools that require extensive command-line knowledge, DSpice abstracts the complexity of circuit simulation while maintaining full access to ngspice's powerful commands. This makes it ideal for:

- **Students & Educators**: Learn circuit theory without the steep learning curve
- **Hobbyists & Makers**: Prototype and test circuits before building
- **Engineers & Researchers**: Rapidly model and validate analog designs
- **Open-Source Advocates**: Access professional-grade simulation tools without licensing costs


Technology Stack
~~~~~~~~~~~~~~~~~

- **Simulation Engine**: ngspice (SPICE3f5-based)
- **License**: MIT License
- **Platform**: Cross-platform (Windows, future Linux and macOS)
- **Programming Language**: ElectronJs (JavaScript/HTML/CSS) for the frontend and Node.js for the backend.


**DSpice combines the accuracy of industry-standard simulation with the accessibility of modern design tools — all while remaining 100% free and open-source.**
